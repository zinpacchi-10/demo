Inner Text

Inner text is a property of an element that represents the text content of the element and its descendants. It is used to get or set the text content of an element, excluding any HTML tags or child elements.

In this example, we have a list of fruits, and we will use the innerText property to retrieve and display the text content of the list items.

  • 1 mango
  • 2 apples
  • 3 oranges
  • 4 bananas
  • 5 grapes
  • 6 strawberries
  • 7 kiwis
  • 8 pineapples
  • 9 watermelons
  • 10 mangos
